# LabPresta - Sistema de Préstamo de Equipos de Laboratorio

Aplicación de escritorio desarrollada en Java (Swing) con persistencia en archivos CSV para la gestión de inventario, usuarios y préstamos de equipos de laboratorio para la Lcda. Torres.
